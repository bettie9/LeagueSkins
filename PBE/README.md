## How to use

1. Download the updated package from Sunshine’s PBE tab or the links above.
2. Replace the previously installed PBE copy and enable the new package.
3. Select the champion’s **default skin** in League.

Use one skin or chroma per champion. Different champions share the same rebuilt shader table; replace all older enabled PBE packages before combining them.

These packages use the current live shader table and native 64-bit material names. They have passed package and import checks; in-game confirmation remains pending.

This package update does not update the LTK Patcher DLL. A patcher error reading the original game BIN requires separate patcher compatibility work.

The five True Damage skins and 28 chromas have moved to the [Live catalog](../index.json). They are not included here.

A PBE installation is not required.
