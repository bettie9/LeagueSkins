## How to use

1. Choose a skin or chroma above and select **Download raw file**, or browse Sunshine’s **PBE** tab.
2. Import the `.fantome` into Sunshine and enable it.
3. Select the champion’s **default skin** in League.

If a new skin is missing from the PBE tab in your version of Sunshine, you can still download and import its file manually.

Use one skin or chroma per champion. Each chroma works on its own. Packages for different champions can be enabled together.

The five True Damage Know My Name skins and their 28 chromas are now in the [Live catalog](../index.json), rebuilt from patch 16.21. Replace previously installed PBE copies with those Live packages.

The new K/DA skins and their 22 chromas have passed package checks; in-game confirmation is still pending.

A PBE installation is not required. The remaining K/DA packages were built for live patch **16.20**; their compatibility with 16.21 has not been reverified.
