## How to use

1. Choose a skin or chroma above, open its file and select **Download raw file**.
2. Import the `.fantome` into Sunshine and enable it.
3. Select the champion's **default skin** in League.

You can enable these packages for different champions together. Use one skin or chroma per champion. Each chroma works on its own; you do not need to enable its main skin too.

When updating, replace your older PBE packages with the new versions.

A PBE installation is not required. These packages are for live patch **16.20**.
