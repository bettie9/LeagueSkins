# League Classic skins

Patch 16.19: **72 champions, 1,716 skins/chromas/variants**.

Packages are built from installed Jade game assets. Enable one package per champion with LTK, or use Sunshine's Classic tab. Each package targets slot 0 and all existing 300-series Classic slots for that champion.

Layout: `classic/<Jade alias>/<full Jade skin id>.fantome`. `index.json` is the download catalog.

All packages passed BIN/WAD structural and byte checks. One package per champion passed a combined 72-WAD LTK Overlay 0.9.5 build. The user confirmed the Dynasty Ahri and Annie-Versary trials in game; other skins are not all game-tested. Rebuild after game patches.

Some pets/forms have no matching per-skin asset: the builder uses the chroma parent or existing base auxiliary. Twisted Fate slot 35 has no public name and is labeled Variant 35.

Built by Sunshine. Game assets and character names belong to Riot Games.
